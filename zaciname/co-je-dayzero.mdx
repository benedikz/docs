DAYZERO Portál je webová aplikace, kterou provozuje komunita serveru **DAYZERO.CZ**. Slouží jako rozcestník mezi hráčem, RP postavami a samotným herním serverem.

## Co portál umí

  <Card title="Správa identity" icon="id-card">

  <Card title="Postavy a deníky" icon="book-open">

  <Card title="Herní statistiky" icon="chart-line">

## Jak portál souvisí s herním serverem

<Frame>
```
DayZ klient ──► herní server DAYZERO ──► relay logy ──► Portál
                                              │
Hráč ──► webový prohlížeč ──► Portál ◄────────┘
```
</Frame>

- **Herní server** běží zvlášť. Portál ho neřídí, jen o něm sbírá data.
- **Whitelist** je most: na server pustí jen hráče se schválenou žádostí.
- **Relay** je formát logů, který server posílá portálu po SFTP. Z něj se počítá vše od „kolik hodin jsi hrál” po jednotlivé zabíjení zombíků.

## Komu portál slouží

| Role        | Co tu dělá                                                         |
|-------------|--------------------------------------------------------------------|
| **Návštěvník** | Prohlíží veřejné profily, frakce a deníky.                       |
| **Hráč**       | Spravuje účet, postavy, frakci, žádá o whitelist.                |
| **Vůdce frakce** | Spravuje frakční gallery, deník, členy a pozvánky.             |
| **Admin**      | Schvaluje postavy, posuzuje whitelist, spravuje webhooks a uživatele. |

## Technologie pod kapotou

- **PHP** + **MySQL 8** (vlastní lehký framework, žádný Symfony/Laravel)
- **REST API v1** pro frontend i externí integrace
- **OAuth2**: Discord, Steam (OpenID 2.0)
- **Cron** pro relay ingest, achievement check a další úlohy
- **Hostinger SMTP** pro transakční e-maily

Detaily najdete v sekci [Pro vývojáře](/vyvojari/architektura).
