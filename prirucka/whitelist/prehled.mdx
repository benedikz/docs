Whitelist je seznam hráčů, kteří mohou vstoupit na herní server DAYZERO. Bez něj se na server nepřipojíte — server kontrolu provádí na úrovni Steam ID.

Stručný úvod k podání žádosti je v [Začínáme → Whitelist žádost](/zaciname/whitelist-zadost). Tady najdete detaily celého procesu.

## Klíčová pravidla

| Pravidlo | Hodnota |
|----------|---------|
| Maximum aktivních žádostí | **1** (PENDING nebo APPROVED) |
| Lze žádat opakovaně po zamítnutí | ano |
| Lze žádost smazat | jen admin |
| Lze žádost upravit | ne (po zamítnutí podáte novou) |
| Stav synchronizace na server | denně přes `WhitelistSyncJob` |

## Životní cyklus

<Steps>
  <Step title="Podání">
    Vyplníte dotazník na `/u/whitelist`. Status: **PENDING**.
  </Step>
  <Step title="Posouzení">
    Admin si dotazník přečte a rozhodne.
  </Step>
  <Step title="Schválení (APPROVED)">
    Vaše Steam ID se přidá do exportu pro server. Většinou do hodiny můžete na server.
  </Step>
  <Step title="Zamítnutí (DENIED)">
    V `denial_reason` najdete důvod. Můžete podat novou žádost (čítač `attempt` se zvyšuje).
  </Step>
</Steps>
